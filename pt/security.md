## GitHub

Consulte o código e os projetos da comunidade no [GitHub](https://github.com/bitdevs-maputo).

## Divulgação responsável

Se encontrar uma vulnerabilidade de segurança que afete a BitDevs Maputo ou os seus serviços, envie um relato privado. Cifre-o com a chave pública acima e envie para [bitdevsmaputo@gmail.com](mailto:bitdevsmaputo@gmail.com). Inclua informação suficiente para reproduzir o problema, mas evite aceder, alterar ou partilhar dados de outras pessoas.
